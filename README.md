# Degenerate’s Advisor v0.8.12
NFL Props Phase 2 + Consistency

## Changes
- Reconciles the post-analysis status banner with the same eligibility gates used by visible PLAY/LEAN/WATCH/STAY OFF cards.
- Adds NFL prop normalization for core DraftKings yardage/volume markets.
- Requires valid player ID/name, matched future NFL game, numeric line/price, supported market, and DraftKings sportsbook.
- Deduplicates identical prop rows.
- Adds deterministic shadow projection/classification helpers.
- NFL props remain research-only SHADOW data and cannot enter official Best Bets.
- v8.9 sport isolation, v8.11 partial-AI recovery, and all official game-market model functions remain frozen.

No claim is made that the public dashboard currently has a live DraftKings player-prop feed. This release validates the ingestion/model foundation for such a feed.
