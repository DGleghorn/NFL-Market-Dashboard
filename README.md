# Degenerate’s Advisor v0.8.8

Performance & UI Cleanup release.

- User-facing header now shows only `V0.8.8`.
- Cached last-known-good slate renders before live refresh.
- Automatic live refresh runs in the background instead of blocking startup.
- A failed background refresh keeps the saved card visible.
- PGA startup refresh is also non-blocking.
- Raw Workers AI batch output is collapsed under Advanced diagnostics.
- NFL, CFB and PGA model identifiers remain frozen from v0.8.7.
