# AI Market Terminal — V0.7.3 Decision Integrity

Production hardening release built from the validated V0.7.2 football baseline.

## Highlights
- WATCH cards now explain the exact failed integrity gate instead of using contradictory generic copy.
- Number-dependent WATCH cards show a deterministic TAKE AT target; evidence/staleness failures tell the user what actually needs to change.
- Slate Summary is now deterministic synthesis of already-verified decisions. Raw Workers AI/model telemetry stays in Developer Mode.
- Official historical record now contains immutable pregame TAKE recommendations only. LEAN/WATCH/PASS are retained separately for research.
- Official TAKEs freeze sport, week, matchup, DK wager/price, quant edge, evidence, Top Play status, model version, snapshot, and pregame context.
- Exact-week settlement supports WIN/LOSS/PUSH, 1-unit accounting, ROI, Top Play record, average odds, and DraftKings CLV when a trustworthy closing market exists.
- Open official TAKEs are checked for settlement automatically after a successful analysis; manual settlement remains available.
- NFL/CFB history remains sport-scoped; Overall intentionally aggregates both.
- PGA remains fail-closed.
