RELEASE PURPOSE
V0.7.7 correctly made the deterministic football engine authoritative, but a TAKE card could still display raw AI explanation/risk text that contradicted the deterministic decision. The deployed DET/CAR example showed a verified +2.9 deterministic edge while Full Analysis said the supplied market data did not establish an edge. V0.7.8 removes that presentation contradiction without changing the V0.7.7 NFL/CFB classification formulas.

IMPORTANT PLAYABLE-NUMBER NOTE
For an OVER with fair total 53.4 and a required 2.5-point TAKE edge, the mathematical boundary is 50.9. Because the app only presents conservative half-point football numbers, the last acceptable displayed OVER is 50.5, not 51.0. The same conservative direction is used for UNDER and spread boundaries.

BROWSER LIFECYCLE LIMITATION
A local headless Chromium dump was attempted. Chromium timed out before producing a usable DOM (RC 124), consistent with prior sandbox behavior. Therefore physical iPhone rendering, live ESPN/DraftKings responses, and the deployed Cloudflare Worker path are NOT claimed as locally browser-verified. The user's deployed iPhone smoke test remains the authoritative end-to-end runtime check.

NO MODEL RECALIBRATION IN THIS RELEASE
NFL thresholds, CFB thresholds, market-shrinkage weights, noise floor, decision fingerprints, and official classification logic are intentionally unchanged from V0.7.7. This release fixes presentation/decision-object integrity so model performance can begin accumulating against a stable football formula.
